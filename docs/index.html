Agent Hub

A local supervisor for long-running OpenAI Codex and Codex CLI jobs—including Codex profiles authenticated through ChatGPT—and for Cline/DeepSeek executors.

What does Agent Hub supervise?

OpenAI Codex planning

Invoke Codex only when a goal needs planning, review, or a next-step decision.

Cline and DeepSeek execution

Delegate bounded edits, tests, builds, and long-running work to the configured executor.

Processes and training

Persist state, detect stalls, recover after restart, and monitor child processes without model polling.

Frequently asked questions

How do I keep Codex running after VS Code or SSH disconnects?

Agent Hub tracks tasks through a local daemon. Executor and training processes can continue independently, and recovery can reattach after restart.

Can it work with a Codex profile authenticated through ChatGPT?

Yes. Agent Hub launches the installed Codex CLI and leaves authentication in Codex's own provider profile.

Does monitoring consume OpenAI Codex or DeepSeek tokens?

Mechanical checks use local process state, SQLite records, exit codes, timestamps, and logs. The planner is called only when judgment is required.
